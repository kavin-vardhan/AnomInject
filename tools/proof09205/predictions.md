Part A changes census output only. `IAI.TexCorrupt.Census vt` uses the existing in-view scope; `IAI.TexCorrupt.Census all vt` uses all renderable actors. Existing commands retain their behavior. Diagnostic output contains counts and histograms, never object or asset identifiers. The all-reasons evaluator supplies VT-only refusals; dependency-unassessed components are reported separately and never advertised as complete eligibility.

Counts use component-material-slot binding occurrences. Stack histograms count each compiled stack once per component-material-slot, not once per layer. Complete-component format sets require every required VT layer to be readable and within the set. The expected single-layer and three-layer fixture counts will be frozen from the authored fixture recipe before the census runs. A count mutant must fail the expected-vs-printed checker. The diagnostic call must not change bindings, material identity, source texture resource/producer handles, residency settings, or private resource/producer counts. Passive page residency can vary with rendering; no diagnostic request/load/residency operation is permitted.

Part A must pass normal and strict Editor/game builds with zero errors and warnings, lever audit, string scan, archive rehash and its fixture/can-fail checks before its feature-only push. Part B starts only after that push.

Part B retains 512 pages, 120 attempts and 10 seconds as the accepted prefetch bounds. Every required layer must be replaced atomically and the actual combined allocation's page-table entries must be proved at the intended levels, including producer mip bias and page-table-layer mapping. If the public API cannot prove this, stop with NEEDS-DECISION. Standalone readiness cannot authorize binding.

Identity: native 1920x1080, every frame including bind/restore edges, target and both controls MAD <= that run's null maximum + 0.05, unchanged frozen criterion. Positive: at least five targeted and three Auto fires in both PIE and staged, separately measured blur of color, normal and roughness patterns, target-only masks, annotation == labels, no labelled frame without a measured mask, E1 t50 zero unflagged, raw onset/offset zero frames off. Can-fails: release and accepted single-layer base refuse with zero events; partial-layer, premature-readiness and no-bind mutants must fail the corresponding gates. Final regression: hold, ordinary proxy, single-layer proxy_vt, UV and normal, three fires each in PIE.

Bench launches require no foreign editor and no foreign GPU-heavy process, sufficient memory and disk floors. A blocked engine gate is rechecked every five minutes for at most four hours. Builds may continue. Only owned processes can be closed, by PID. No engine edits, global/pool VT bias, source residency forcing or protected-ref changes are authorized.
