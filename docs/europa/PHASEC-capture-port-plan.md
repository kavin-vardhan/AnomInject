# Europa: Phase C capture port to stock 4.25

094-30, 2026-10-31. Source baseline: `abb240bc0431b53e5b21809986da59b534efe7b1`. **Plan only; nothing enabled or built.** Phase A's pictures came from the host probe, not AnomalyCapture. Capture, shaders and control remain disabled on 4.25. The priority is plugin frames, then exact labels, then masks. Texture anomalies, throughput, network control and the dashboard wait.

## Decision and measurement boundary

Use the existing **asynchronous backbuffer route for C1/C2**, with a 4.25 RHI adapter. It captures the selected game viewport, including any game UI; the fixtures run with HUD/overlays off. Do not substitute synchronous `ReadPixels` or the probe's screenshots. The 5.1 after-pass SVE cannot simply be enabled: 4.25 lacks its hooks and view-family extension-data interface. C3 adds a separate 4.25 mask SVE, keeping the qualified colour route and its frame identity.

The inventory below covers the three modules' 58 C++ headers/translation units, their three shaders, build rules and shared timing/geometry dependencies. **Same** means the required API exists, not that runtime behaviour has passed. **Different/missing** requires an adapter or an explicit unavailable capability. PHASE0's measured rows are reused; newly checked signatures refine, rather than contradict, its class-presence findings.

**No diagnostic compile:** the enable switches are hard-coded in module rules, not external overrides (`AnomalyCapture.Build.cs:346`, `AnomalyShaders.Build.cs:15`). A meaningful two-module attempt needs copied rules/source, an isolated target, UHT outputs, response files and link outputs; the 4.25 rules deliberately use no PCH. The available qualified target writes the bound host. Even an installed-engine UBT query normally writes a user XML cache (`Programs/UnrealBuildTool/System/XmlConfig.cs:76-83`). Establishing all-scratch output isolation is extra build work; a partial syntax invocation would miss UHT, exports and shader compilation. Under the owner's optional/lean instruction, this job records **source incompatibilities, not purported compiler errors**. C1 starts with the actual isolated build; no engine edit is proposed.

### C2's non-negotiable timing contract

Keep the existing label policies and schema: `AnomalyActiveSource.h:23-38`, `AnomalyLabelSync.h:53-113`, `AnomalyLabelWriter.cpp:852`. The late sampler already freezes active state, installed state and geometry (`AnomalyCaptureSubsystem.cpp:6099-6215`). Bind/unbind only the 4.25 anchor; leave the 5.1 anchor and handlers intact. PHASE0 §1 proves the tickable-before-PostActorTick ordering on stock 4.25, **not** on paused/TimeOnly ticks. When no eligible tick occurs, issue no new labelled frame; do not sample from `OnEndFrame` as a substitute.

Carry an immutable `{run epoch, world/view owner, capture request, session index}` from snapshot to render-family acceptance, backbuffer copy, readback and writer. Accept one eligible game view/window; reject stale, duplicate or mismatched families. A plugin-owned bounded registry replaces the absent family-data attachment; entries own scalar identity/receipts, not a dangling view pointer. Drain by key, never “latest state” or GPU completion order. Writer completion and final counts must agree; stop/travel drops pending unmatched work explicitly. A short run boundary between maps checks that an old epoch cannot label a new map; this is capture correctness, not the deferred A5 lifecycle matrix.

Adapt m40's pixel-set comparison, not its host-specific actor names. Its existing reader is `CaptureBench/tools/p9_hidden_set.py:202,268-339`; preserve the frozen separation ratio 5.0 for the blink case and the `ALIGNED`/shift/residual meanings. The existing `IAI.Bench.SynthTickOrder` dispatch lever is in `AnomalyInjectorSubsystem.cpp:577,1543`; use it only with `-IAIBench`, restore it to off, and require its effective echo. Use fixed pixel regions and separately calibrated clean/active references for light and LOD; label bits, fire logs and stencil masks must not define the observed pixel state. Count only sufficiently separated observations; ambiguity fails qualification. The can-fail is an evidence mutation, not four old/new binary runs. See [m40 prediction](../predictions/2026-09-02-m40-order-independent-label-sampling.md) and the historical handoff's §3.4/§4: the label gate remains a capture-admission condition.

P9's engine tick-mode pin is a separate issue from the late sampling anchor. Stock 4.25 has no fork tick-mode symbol (PHASE1 §C.3); retain `tickpin_compiled=0`, never claim a pin test passed. Standard FApp capture pacing remains save/set/restore. On Europa's fork, require a later source/behaviour reading before selecting a pin adapter; do not guess a private FApp symbol or change 5.1's probe.

### C3's proposed spatial gate

Freeze an independent binary visible-change region from paired clean/active RGB, bounded to the target, with a clean-clean noise floor. For the stable opaque fixture, propose **IoU >=0.90 and recall >=0.95 on every counted active frame**, plus <=1% mask spill outside a one-pixel dilated target region. Report strict and boundary-tolerant scores; an empty reference is a failure, not perfect overlap. These are proposed thresholds, not measurements. Do not lower them after results.

Distinguish semantics: a hidden-object target mask is the missing surface's counterfactual silhouette, derived independently from its visible clean reference; the drawn-pixel channel must be zero while it is hidden. A light anomaly's affected-light footprint need not equal an object stencil: require the existing declared target-mask semantics, score visible change within that target, and report off-target illumination separately. LOD must retain the measured cube/sphere target and visible model choice. Occluders are excluded using visible reference pixels, never a box filled from label coordinates. Preserve output-to-internal-rect mapping, reversed-Z comparison and event-owned stencil allocation; never call an unavailable mask `MEASURED_ZERO`. If RGB cannot be associated with the mask's family, fail the pair before writing a dataset row.
