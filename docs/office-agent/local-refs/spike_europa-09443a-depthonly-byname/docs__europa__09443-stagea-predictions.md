# 094-43 Stage A: frozen GD3 admission

Written before any new fixture launch. This spike remains fixture-only and is not merged. The accepted 09443a reference/02, seed 4242, all four routes, 2352-frame schedule, same-index/view/event pairing, IoU 0.98, hidden nonempty test and magenta classifier remain fixed. GD4 alone moves lighting owner-group mismatches to a separate note; no non-lighting or pose/event mismatch is excluded.

Visible census and event ID pixels require abs(privateZ-sceneZ) <= tolerance. Explicit logically hidden event components use front/equal admission; the selected-event bit is also required. Both use the same tolerance. The GPU uses reversed Z, so front/equal is privateZ >= sceneZ-tolerance (RHIDefinitions.h:725). Rejected pixels do not replace a previously admitted ID or depth. Clean drawn blinking frames retain census ID but no selected mask.

Tolerance is frozen as 4 / (2^24 - 1) = 0.0000002384185933 in device-depth units. D3D11Device.cpp:38-42 selects D32 float by default; :140-150 maps PF_DepthStencil to D24 UNORM or D32 float. Over [0,1], the spacing below 1 for binary32 is 2^-24, bounded by the D24 step 1/(2^24-1). Budget one full step for each depth store and one for each float representation/conversion, four total. Both passes use the same material/VF positions, proxy LOD, captured view and exported bindings (MeshMaterialShader.h:74-112). This is a quantization allowance, not a guarantee for every possible material arithmetic difference; discrepancies beyond it fail the frozen gate. It is not adjusted from measured images. The legacy reference keeps its original comparison tolerance.

Scene depth comes from CreateSceneTextureUniformBufferSingleDraw with ESceneTextureSetupMode::SceneDepth (SceneRenderTargets.cpp:3421-3431), consumed through SceneTexturesStruct.SceneDepthTexture. No private Renderer access is added. AnomalyHiddenClass::IsLogicallyHidden snapshots physical anomaly hiding on the game thread; selected live-event bits remain frozen on the same request.

Predictions: disocclusion-only masked/WPO IDs disappear until current scene depth contains them; A-P3 passes every nonempty object/frame at IoU >=0.98 and all hidden-blink frames stay nonempty. A-P2 warm material cache misses remain zero. A-P4 outline-on versus outline-off has zero new magenta in every saved frame. A-P5 has zero enabled/tagged components and unchanged r.CustomDepth. Any Stage A gate failure stops before Stage B. The existing spike's per-object allocations/draws and blocking cost probe remain experimental here; Stage B must replace those shortcuts.
