Facts from the A6 fixture-authoring runs (094-26r 10-29, 094-28 10-30), verified against E:\EpicGames\UE_4.25 source:
- **The editor spawns `UnrealBuildTool.exe -Mode=ValidatePlatforms -allplatforms` ~9.5 s into init** (TargetPlatformManagerModule.cpp:996-1000 SetupSDKStatus; ValidatePlatformsMode.cs:35-60 only logs VALID/INVALID). It is not QueryTargets (DesktopPlatformBase.cpp:882). 094-28's FC6 guard allowed only QueryTargets (an inference from 094-26r, whose UBT argv was not retained, and which my 094-26 review called a fit) and stopped the smoke.
- **4.25 FPostProcessSettings has no AntiAliasingMethod / bOverride_AntiAliasingMethod** (EAntiAliasingMethod only in RendererSettings.DefaultFeatureAntiAliasing). The A5 recipe sets them (author_425_fixture.py:88-89): it fails in a real session; the stub harness cannot see it.
- UHT `Interp` implies CPF_Edit|CPF_BlueprintVisible (HeaderParser.cpp:3916-3920), so interp properties are Python attributes.
- The embedded python27.dll (Py_InitializeEx) honors PYTHONDONTWRITEBYTECODE; without it imp.load_source writes .pyc beside the source (measured via ctypes). The kit's editor env carries it.
- `-NoAnalytics` is added only on the crash-time CRC launch (WindowsPlatformCrashContext.cpp:840-842); the startup monitor (:1106-1109) never gets it. Editor analytics/session-summary writer are gated by bSendUsageData (EngineAnalytics.cpp:117-183).
- Each session rewrites 9 `Intermediate\Config\CoalescedSourceConfigs\*.ini` (byte-identical so far) and writes asset-registry caches, PackageRestoreData.json; the engine purges Saved\Config\CrashReportClient\UE4CC-* after 2 days.

- Every map save writes `Saved\Config\WorldState\<CRC32 of UTF-16 package path>.json` (EditorActorFolders.cpp:132-149; EA_Core 1202994220, EA_Travel 2530609069) and a `Saved\Backup\<map>_<stamp>.umap` copy of the pre-resave version (PackageBackup.cpp:101-131). 094-26c stopped on this; FF2 (094-26c ruling) records all of host `Saved\` except `Saved\Config\**\*.ini`.
