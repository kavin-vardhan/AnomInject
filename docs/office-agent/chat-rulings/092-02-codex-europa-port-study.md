## 2. The four known walls, with concrete replacements

### Reflected tickable parent

**MEASURED (stock 4.25).** The 070 §3.9 idea is structurally sound: one literal plugin UCLASS parent deriving from UWorldSubsystem and FTickableGameObject can be shared. But a **verbatim** clone of 5.1 is insufficient. The 5.1 class relies on IsAllowedToTick (WorldSubsystem.cpp `:57`) and FTickableGameObject invokes it (`5/Runtime/Engine/Private/Tickable.cpp:141`). Stock 4’s loop tests tick type/IsTickable/world without that call (`4/.../Tickable.cpp:139`). Its tick type is expected to be invariant (`4/.../Tickable.cpp:53`). UWorldSubsystem in 4 also lacks DoesSupportWorldType; USubsystem::ShouldCreateSubsystem exists (`4/Runtime/Engine/Public/Subsystems/Subsystem.h:61`).

**INFERRED — proposed shared shim.** Put `UAnomalyTickableWorldSubsystem` in Injector’s Public compatibility area, with one literal reflected declaration and identical bases on both engines. Implement ShouldCreateSubsystem to preserve Super’s decision and Game/PIE-only creation for these five classes. Preserve IsTemplate/CDO exclusion, GetTickableGameObjectWorld, stat identity, Initialize/Deinitialize chaining and initialized-state lifetime. Use Conditional for eligible tickables, Never for templates, and an IsTickable initialized gate that works in 4; retain an IsAllowedToTick-compatible method for 5 as appropriate. Do not return Always and expect IsTickable to protect 4. Keep engine differences in .cpp/non-reflected helpers. Review double registration, PIE/editor worlds, multiple worlds, pause behaviour and teardown before accepting the clone.

**MEASURED (stock 4.25).** UHT is not a C++ preprocessor. `4/Programs/UnrealHeaderTool/Private/HeaderParser.cpp:3499` recognizes a small conditional vocabulary; `:3517` errors on unknown defines in class/global parsing, and `:9265`–`:9274` forbids reflected constructs inside unsupported preprocessor blocks. 5’s C# parser excludes Unrecognized blocks (`5/Programs/Shared/EpicGames.UHT/Parsers/UhtHeaderFileParser.cs:882`–`:888`). The literal-parent failure and asymmetry were also recorded in `M/docs/CHAT-HANDOFF-070-europa-e1-blocked-and-parked.md:53`–`:62`. This is that handoff’s **G232**, not an assumption based on a possibly reused number in current gotchas.

**MEASURED (stock 4.25).** The inheritance parsers retain identifier tokens: 4 reads BaseClassNameToken then stores its Identifier (`4/Programs/UnrealHeaderTool/Private/HeaderParser.cpp:9587`–`:9593`); 5 calls ParseInheritance and stores SuperIdentifier (`5/Programs/Shared/EpicGames.UHT/Parsers/UhtClassParser.cs:100`–`:103`, helper `UhtParserHelpers.cs:25`). Neither provides a general C++ alias/macro expansion solution for switching reflected parents.

**INFERRED.** Do not macro-substitute a reflected base, wrap alternative UCLASS/UPROPERTY definitions in ENGINE_MAJOR_VERSION, or trust a 5.1 UHT pass as evidence for 4.25. Replace TObjectPtr members with common UPROPERTY raw-pointer declarations, retaining strong reflected reachability. Move engine-specific server members behind an opaque non-reflected implementation. Changing the parent alters reflected ancestry on 5.1: even if ticks match, a cast to UTickableWorldSubsystem no longer matches.
