## 2. The E1 fixes (declared 2026-09-30, before any 089-03 leg)

- **G395 — a judged frame never sits inside its own reference.** (a) the onset reference excludes the event's own unlabelled
  fire rows (the kit's `pre_clean`); (b) the offset reference drops leading unsettled frames by a leave-one-out test against the
  frames after them and, once settled, trailing unsettled frames against the frames before them (the kit's rule); if it never
  settles the offset is CENSORED and read against the onset reference; (c) a judged frame that is a member of the reference it is
  read against (≥ 3 frames) is read against the reference WITHOUT it (median and noise); (d) an event's span starts no earlier
  than `PREV_SETTLE = 4` frames after the previous event's last labelled or transition frame, so a neighbour's delayed frame
  cannot enter it (RD3's start −14).
- **G405 — a one-frame label run is not scaled by its own post-label noise:** a run whose off half holds no labelled frame is
  scaled by its own `depth_on`.
- **G406 — the null is aligned by game time, frame by frame:** each leg frame is divided by the null sharpness interpolated at
  the same `t` (a bracketing null gap over 4.5 frames refused); no lag search and no own-detrend fallback when a null is given.
  An event whose window `[first label − 12, span end]` reaches a frame outside the null's time range reads
  **UNJUDGEABLE-NULL-RANGE** (a refused gap: UNJUDGEABLE-NULL-GAP) and is never judged; a leg whose null does not cover
  `t(first label − 12) .. t(last label) + 2 s` reads **UNJUDGEABLE-NULL-COVERAGE** unless a judged event FAILs, and a judged
  FAIL under the aligned null is REAL until shown otherwise (089-01 ruling 1).
