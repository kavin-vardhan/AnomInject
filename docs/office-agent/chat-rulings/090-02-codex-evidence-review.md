1. **F1 — HIGH: a retained FireWindow entry can label a clean picture after an early revert.** `F/Source/AnomalyInjector/Public/AnomalyLabelSync.h:63` makes FireWindow annotation membership depend only on the projected box being on screen, ignoring active state. `F/Source/AnomalyCapture/Private/AnomalyActiveSource.h:27` assigns this policy to missing/corrupted texture, and `:35` assigns it to UV/normal corruption. `F/Source/AnomalyCapture/Private/AnomalyLabelWriter.cpp:712` uses that membership for annotations and `:722` for `labelled`. First, a moving/animated target or camera can expose previously unselected components after the component filtering in F5; the static fixture matrix does not cover this.
