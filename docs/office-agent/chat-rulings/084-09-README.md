## AMENDMENT R1 — the clean-reference span (declared 2026-09-29, 084-08, BEFORE the MASK55 re-check ran)

Governing: `_reviews\084-06-chat-ruling-bench.md` ruling 5. It applies **uniformly to every anomaly type** judged by the E1
D-signal evaluator (`084-09-eval.py`, `REF_AMENDMENT = True`), and the office kit (087-01) is to take the same rule.

- **An onset reference uses only clean frames at least 4 frames (`PREV_SETTLE`) after the previous event's last labelled or
  transition frame.** Frames inside that settle are the previous event's tail and are never a reference.
- **If fewer than 4 such frames exist (`REF_MIN`),** the event's own post-event clean frames are added: after its last
  labelled or transition frame + 2 (`POST_SKIP`), at most 6, and before the next event.
- **If there are still fewer than 4,** the event is **CONFOUNDED-REFERENCE**. That is a class, counted and reported **per
  type**, never silently dropped, and never a PASS.
- When the pre-event window alone has >= 4 clean frames beyond the settle, nothing changes from 084-06.
- What it answers: 084-06's one missing_texture FAIL in MASK55 (`StaticMeshActor_85`, +1 at onset, threshold at 97 % of
  depth) had its reference inside a 4-frame gap that held the previous event's tail. If it passes with an uncontaminated
  reference it was a reference confound (missing_texture stays SYNC-PROVEN); if it still fails it is a real +1 for the next
  source round.

### The partial-flag guard (m52 E1, every threshold, release = t50)
- A `partial` frame is **confirmed partial** if its measured drop is above the calibrated null band (the edge's own
  threshold, `max(5 sigma, 2 %, null excursion)`), **flagged-invisible** if within it.
- A partial frame excuses its off state only if it is labelled AND its `stuck_mip.render_textures` shows >= 1 texture at
  level `held`. Flagged-invisible frames with that record are **counted, not failed**; without it the event FAILS.
- `partial` on an unlabelled frame never excuses anything (a flag cannot cover a late label) and FAILS.
- **Any unflagged off frame FAILS** (the 084-06 transition gate, now fed only temporal flags and record-backed partial flags).
- `unresolved` frames are reported apart; **an off frame whose only reason is `unresolved` FAILS (to investigate)**.
- Temporal reasons (`temporal_aa`, `hide_return`, and a legacy `transition: 1` without a reason on old banks) excuse as in
  084-06; a temporal flag on a leg without temporal AA FAILS. `partial` / `unresolved` are AA-independent and exempt (G368:
  the inherited rule would have false-FAILed every AA-off partial onset; the selftest caught it).
- Per edge (onset / mid / offset) the partial-frame count is histogrammed per event; **warm-up events** (the capture's first
  event, or one starting before the settle skip) are reported separately AND included; an edge longer than 8 partial frames
  is listed for investigation, not failed.
