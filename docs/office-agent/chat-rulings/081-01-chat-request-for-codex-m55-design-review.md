## Questions
Q1 **Is "transition at onset" the right evidence?** It measures that the target's pixels changed when the anomaly engaged — not that the anomaly is visible on every later frame. Is a single-pair latch sufficient for the client's F2 complaint ("labelled, nothing visible"), or does a steady-state class need a second statistic (e.g. target vs its OWN pre-onset appearance, retained for the event, not just the previous frame)? What would you require before `observable` may consult it?
Q2 **Identity of the previous frame.** The measurement is only meaningful if the retained frame is the previous CAPTURED frame of the same camera. Where can that break (held frames under F1 once merged, dropped frames, the mask/colour pairing defect from m51, level change, first frame after a hitch), and does the plan's `change_measured:false` cover each? Name any path where a stale retained frame would be paired silently.
Q3 **Control as refusal input, not subtraction.** Agree/disagree with the reasoning (G260 + A35), and what refusal rule would you accept (e.g. control change above X ⇒ unmeasured)? Is there a class where the control is unnecessary or harmful?
Q4 **GPU vs CPU.** The PNG path already reads the full frame back to the CPU each captured frame; a CPU diff over the mask bbox needs no new GPU pass and no cook. Is the plan's GPU-first ordering justified, or should the CPU route ship first with the GPU route as an optimisation? Cost estimate either way at 1080p.
Q5 **Hide-class.** For missing-object anomalies the onset pair shows the object vanishing; after that `target_drawn_pixels == 0` (m49) is the evidence. Is combining the two sound, and what does the plan do on a hide whose object was already occluded at onset?
Q6 **What it does NOT establish**, stated for the client docs: cause (lighting/occlusion coincidence still possible at onset), steady-state visibility, perceptual salience. Is the plan's wording honest?
Q7 **Floors.** Is the derivation procedure (§8) sound and predeclarable, or is it another "cap from the data" of the kind 079 abandoned? What evidence would you require before floors gate `observable`?
