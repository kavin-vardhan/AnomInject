## 1. Rulings — all nine findings ACCEPTED. The plan is rewritten around them, not patched.
R1 **Staging (F3, Q3).** m55 v1 = MEASUREMENTS ONLY. m49 `observable` predicate unchanged byte-for-byte. No `present`/`absent` verdict word anywhere in v1 output. v1 publishes raw per-row numbers, coverage, reasons, and one durable final per-event record. A calibrated event verdict and any change to `observable` are a LATER unit gated on an owner/client decision (operating contract §3) — the plan says so in its first paragraph.
R2 **Numeric contract (F6, F7).** Canonical pixels = the BGRA8 byte buffer the writer hands to the PNG encoder (post-conversion, so 10-bit/half-float truncation and ties are already applied); the CPU stage reads exactly that buffer. Region = the CURRENT frame's target mask per tag; control = complement of the union of ALL tag masks in that frame (other targets' spill must not pollute the control). Per pixel: max over B,G,R of |cur − prev| in bytes, alpha ignored. Per target per row: `chg_n` (mask pixel count — must equal `target_pixels`, assert and count mismatches), `chg_gt8` (pixels with diff > 8), `chg_hist` = 8 bins over diff [0] [1–2] [3–4] [5–8] [9–16] [17–32] [33–64] [65–255] (so any later threshold can be swept without images), `chg_mean` (mean diff/255, 4 dp). Control twins: `ctl_n`, `ctl_gt8`, `ctl_hist`, `ctl_mean`. Guard BOTH denominators: `n == 0` on either side ⇒ that side unmeasured, reason `empty_region`. Supported delivery = PNG, no resample, one view; JPEG / resample / multi-view ⇒ `chg_measured:false`, reason `unsupported_delivery`. Verifier oracle: `tools/verify_capture.py --change-oracle` recomputes `chg_gt8`, `ctl_gt8` and both means from the decoded PNGs at the producer's own pair ids, same region, same threshold; reports count-vs-count and mean-vs-mean agreement plus coverage; states in its output that agreement validates arithmetic/transport only. Peak selection and the 079 outcomes untouched and reported separately.
R3 **Identity contract (F2 and every row of §4).** Every retained buffer carries an immutable receipt: run epoch, capture request id, session index, view id + family frame, camera pose hash (location/rotation/FOV quantised) + cut counter, rect/extent/format, capture time, delivery-success flag (writer accepted the bytes — not merely armed). A pair is valid only when: same epoch; same view id; `prev.session_index == cur.session_index − 1`; extents and rect equal; both receipts delivered; and the current frame's colour, mask bytes and counts were joined by receipt (request id + view), never by intended session index — the mask-arm coalescing path (~120, ~512) must be handled explicitly. The CPU stage is ordered by session index with a bounded wait (state the bound in frames AND bytes). Enumerated refusal reasons (closed set): `first_frame`, `predecessor_missing`, `predecessor_undelivered`, `out_of_order_timeout`, `epoch_reset`, `view_mismatch`, `extent_mismatch`, `mask_payload_missing`, `unsupported_delivery`, `budget_exceeded`, `empty_region`. Epoch reset (level/world change, run reset, cut counter change) clears the colour holder, mask holder, receipt and any pending phase state together; late results from an old epoch are rejected and counted. Do NOT retain `PendingSnapshots` longer as a workaround. Byte budget: one canonical BGRA8 frame (8.29 MB at 1080p) + receipt, held as a shared immutable ref with the writer — name exactly where the ref is taken relative to the `MoveTemp` of `Frame.RawBytes` and `Result.MaskPixels`. Camera pose hash is published as `cam_moved` (bool per pair) — a CAVEAT field, not a validity rule; moving camera stays supported.
R4 **Temporal contract (F1, F3).** Scope = phase: one contiguous held run (blinking and LOD toggles have many). Per phase: `onset_pair` = (last unheld captured frame, first held captured frame); state `pending` until that pair's measurement resolves; if the onset pair is unmeasured the phase is `indeterminate` — never a reading taken from later quiet pairs. Window = first K=4 held pairs per phase (documented as an experimental budget, not a completeness bound). Retain the phase's last pre-roll canonical frame as `ref` for the window and publish `ref_gt8`, `ref_mean` for each window row vs that reference under the current mask (gradual-change catch; caveat: screen-space under motion, `cam_moved` accompanies it; never used for a negative call). Rows carry running aggregates NAMED as running (`chg_gt8_max_sofar`). Final per-event record — durable, in the run summary AND a per-run `change_evidence.jsonl` (name it; not only `labels.jsonl`, which delivery mode may disable) — with per-phase entries capped at 8 + `phase_count`, coverage (`pairs_required`, `pairs_measured`, reason histogram), final aggregates. Finalisation events, each with what is written: phase end, event end, drop, teardown, run end. Results arriving after finalisation are rejected and counted (`late_results`).
R5 **Control (F9, Q3).** No subtraction. No control threshold in v1 (nothing to calibrate against); raw control published for every valid pair. Two separate fields: `chg_measured` (pair arithmetic valid) and `chg_eligible` (v1: always equals `chg_measured`; reserved for the later policy). Doc line: a low control value is not a causal certificate.
R6 **Hide class (F8).** `target_drawn_pixels == 0` is supporting evidence only; the depth-silencing case (drawn == count on a correctly hidden object, ~4023) stays an accepted case; already-occluded-at-onset (empty mask) ⇒ `empty_region` ⇒ indeterminate; the onset pair's prev-frame `prev_target_pixels` is published as the pre-onset visibility record.
R7 **Bench cases (F4).** Keep `IAI.Bench.StuckMipNoHold` as a no-label control: expect zero labelled rows and a final record `indeterminate`, reason `no_labelled_frames` (add that reason to the enum). Declare two NEW bench-only anomalies (class, files, lines; gated like `IAI.Bench.*`; never in the auto pool; not in the catalogue or client readme): `null_effect` — picks a visible static-mesh target, enters held, arms a mask, changes nothing; `solid_swap` — same picker/arming, swaps the target's materials to a flat unlit colour, reverts on end. Predictions in the plan: `null_effect` onset `chg_gt8/chg_n` within the control's band on every window pair; `solid_swap` onset ≫ control; each run with the camera static and moving; both tick orders.
R8 **Calibration (F5, Q7).** Removed from m55. §8 becomes "Calibration — deferred to its own unit" listing Codex's requirements (independent positive/negative examples incl. the two bench anomalies and owner-eyeballed bench-session examples; calibration vs held-out split; no separation ⇒ no gating; threshold validity range enforced; provenance recorded). G-3 (the Lyra G270 events) becomes an OBSERVATION gate — record their onset numbers, no expected value; Codex's bank probe (target >8 fractions 3.2% / 0.18% / 11.3%) is the prior. No compiled floors.
R9 **Cost (F7, §5).** CPU stage on a worker, never the game thread. A/B/B/A pacing-off at 720p and 1080p; report game-thread ms, worker ms, writer throughput, queue/byte high-water marks, drops, tails. Budget: ≤ +1 ms game thread AND writer throughput unchanged within measurement uncertainty; if the uncertainty exceeds the budget the gate reports UNRESOLVED, not pass. GPU route parked entirely — one paragraph noting it as a future optimisation with identical numeric semantics; no RDG design in this plan.
