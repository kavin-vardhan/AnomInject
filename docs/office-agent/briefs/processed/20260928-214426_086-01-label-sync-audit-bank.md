1. **Enumerate every anomaly that ships on 5 Oct,** from the catalogue and registration at `master` `b5f15a3`. Exclude the bench twins (`null_effect`, `solid_swap`). Note `stuck_low_mip` (being fixed in 084) and `uv_corruption` / `normal_corruption` (m53, still unmerged).

2. **Find usable bank evidence** for each: sessions with every frame saved, labels, masks, and a matched null or a pre-onset reference (the m55 requalification bank, the m49–m52 banks, and so on).
3. **Measure from pixels,** per event, both edges: the first and last pixel-visible frame inside the target region (thresholds from nulls, or pre-onset references with declared noise floors) vs the labelled window and mask window.

   - **m55's `change_evidence.jsonl`** gives per-frame target-pixel change where present; use it as a second, independent witness.
   - Also flag **wrong-object** cases: a visible change outside the target mask that the null doesn't show.
4. **Classify each anomaly** as SYNC-PROVEN (0 frames off on both edges, n events, on which content), DESYNC (the measured offsets), or UNMEASURED (no usable bank evidence).

5. **Part B plan (bench):** the smallest set of bench legs that closes every UNMEASURED anomaly and confirms each DESYNC. Include realistic content where the bank is thin, and note what the owner's environment-pack project would add once it exists. Give the time estimate.
