## 2. The evaluator (id `084-06`)

- **Labels** are `annotation.json` `injected_frames` (for m52 also checked against `stuck_mip.held`); the transition set is
  per event (only the event whose entry carries `transition: 1` is exempt on that frame).
- **m52, edge-local.** ρ(si) = S_leg(si) / S_null(si + lag); reference = median of the 8 frames before the label, two-point
  detrended to the last 6 frames of the span; threshold per edge = max(5 σ local, 2 %, the null's own dip below its trend in
  the matched window). A picture that never returns to its pre-level censors the offset. The 084-04a rules stay (onset
  confirmation, clean suffix, gap censoring, visible-outside-window, masks, purity, contamination). **Failures that depend on a
  censored edge are "ambiguous", not FAIL** (084-04a rule a) — found needed on B3_FIX, whose drift-censored offsets carry
  tails to +8.
- **Other object types** use 086-01's D/P metric with an onset reference before each label run and a separate settled offset
  reference after its transition frames (an unsettled one censors).
- **Second verdict:** the unmodified 086-01 checker on every leg, `transition_present` rows excluded from its references (the
  084-05a note), its raw status and a transition-aware reading of its own edges both reported.
