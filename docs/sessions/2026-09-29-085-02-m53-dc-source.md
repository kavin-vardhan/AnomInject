  (`texcorrupt_draw_test.cpp`), not inside `texcorrupt_pure_test.cpp`.

  block forever) — Codex F3 shows the other side of that choice. A closed trail overrides a non-empty Restoring set.

  §3.3 as written); whether that set can stay non-empty past m52's timeout was not established.

- Scramble scalars are written only in scramble mode; `slot_empty` / `slot_translucent` are not in `AllFinalReasons`, so
  their counters appear only when they occur; `RestoreBenchAssetSlotMid` keeps an empty body in Shipping (called
  unconditionally from AIS).

  none), so a targeted m53 capture from the dashboard refuses `mode_invalid:no_mode` on every burst; the readme gives the
  console route. A product decision (NEEDS-DECISION).
