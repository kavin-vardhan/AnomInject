# 018 — m12: Client delivery mode (2026-07-12, gates GREEN; COMMIT PENDING owner confirm)

## Goal
Ship-to-client capability: a DELIVERY MODE that limits what a capture run writes to disk to only
client-facing files, because the external client runs capture in their own build with no
post-processing step — whatever capture writes IS what the client gets. Default OFF (full fidelity,
byte-identical to m11 apart from the D3 annotation change).

## What was built (comment-free; full editor-closed rebuild — new static console command, Live Coding
distrusted per the m11/Item-2 lesson)
- **D1 toggle + packaged default:** `bool bDeliveryMode = false` on UAnomalyCaptureSubsystem.
  `IAI.Capture.Delivery <0|1>` → `SetCaptureDelivery` (mid-run guarded like Fps/Pace). Packaged default
  read at Initialize via `GConfig->GetBool(TEXT("AnomalyCapture"), TEXT("bDeliveryModeDefault"), ...,
  GGameIni)` — owner sets `[AnomalyCapture] bDeliveryModeDefault=True` in the project DefaultGame.ini;
  console overrides per session, no SaveConfig (G69). Chosen over UDeveloperSettings to avoid a new
  module dep + UCLASS (GConfig is Core; include Misc/ConfigCacheIni.h). Initialize + Status + STARTED
  log lines all surface delivery state.
- **D2 gated disk writes (compute unchanged, uniform path):**
  - run.json: `WriteRunManifest` at StartRun wrapped in `if (!bDeliveryMode)` (never created).
  - labels.jsonl: threaded `bWriteLabels` through FJob → EncodeAndWriteFrame (async) and
    CaptureLabeledShot → AppendRecordAndImage (sync); the IMAGE write always runs, only the
    labels.jsonl append is gated. Set from `!bDeliveryMode` at both the async job build and the sync
    call. Manual `IAI.Capture.Shot` unaffected (bWriteLabels defaults true at its call site).
  - annotation.json + run_summary.json written in BOTH modes.
- **D3 annotation strip (both modes, always) + dead-field tidy:** removed `schema_version` and
  per-anomaly `source_id` from WriteSessionAnnotation, and removed the now-unused
  FSessionAnnotation::SchemaVersion + FSessionEvent::SourceId members and the `Out.SourceId` assignment.
  (run.json/run_summary.json keep their own numeric `schema_version` — D3 names annotation.json only.)
- **D4:** WriteRunSummary gains a `bDeliveryMode` param → `delivery_mode` bool in run_summary.json;
  FinishRun passes it.
