## 5. Deviations and interpretations, stated

- **"Last labelled frame emitted" is applied through unfinalized snapshots for render-truth ids only.** m52's membership
  is decided after arm (render truth), so an unfinalized snapshot can still extend its tail; m53 (FireWindow) is decided
  at arm, so its pending frames cannot reach a frame at or after an m52 admission. Consequence, stated: the m52-partner
  release now depends on readback latency (a few frames), which can shift an eligibility, and so a draw, on legs with
  m52 history; the m53-partner release is unchanged (R + 2).
- **`HandleTrailReopens` is unchanged.** With the barrier an m53 fire cannot be live while an m52 trail can reopen,
  except after the accepted `restore_unresolved` admission (an unresolved trail is not closed, so it does not "reopen";
  if it later closes and then reopens, that is inside the ND-2 exception and counted). Asked of Codex.
- **The overlap counter is broadened** from "labelled m53" to "any m53 entry", to equal the gate chat ruled.
- **ND-2 exception vs the gate:** frames after an unresolved admission may co-enter; the gate reads such a leg INVALID
  rather than PASS or FAIL, and the readme says those frames count.
- **Census grammar change:** the `end` line gains `stats_unchanged=`; the checklist regex accepts only `=1`. The pool
  (live fires, enabled ids) is in the snapshot because the ruling says "never mutates … the pool". First-use config
  echoes from knob resolution can still print if the census is their first caller (no names, no stats).
- **Round-robin counter** advances whenever a targeted m53 fire draws its hold, independent of the apply result (the draw
  protocol's rule), and restarts with every capture (StartRun calls `SetSeed`).
- **Free-running bound** counts the StuckLowMip tick counter (`FramesWaited`) against `StuckMipRestoreTimeoutFrames`, the
  same knob the capture compares against captured frames.
- **Limitation, not changed:** a trail carried into a run that is not render-truth never progresses, so it keeps m53 out
  for that whole run (architecture limits).
