   one texture each, so no material-instance path enters the oracle.

3. **"Only the new fixture files":** the manifest diff adds exactly the 13 declared files and changes exactly
   `CB_TexCorruptLevel.umap` (the actors must be placed in the level; the plan's M1 rule allows exactly this one change).
4. **MainWorld hosts per family** (the plan: one host passing both families). The S1 bank predicts no such host (G394); the
   harness prefers a both-eligible actor and flags per-family picks for chat.
5. **G-SYNC-REG is 8 legs:** 084-09's B5 is added, because B0 / B3 / B9 are read against it (G356).
6. **G-SEED (b)** (MainWorld vs the FIX exe, optional, an exe-only swap) is not in the harness.
7. **Can-fail (a) is read by E2** (G392); B-M53's own arms exercise E1.
8. **EXCL-A accepts the m52 trail-state family** (`trail_open`, `trail_reopenable`, `label_tail` — the 085-02b states) and reports
   the exact state; the plan's literal is `trail_open`. The close line is the real `Capture(m52): RESTORE TRAIL CLOSED`.
9. **EXCL timing is calibrated, not assumed:** `P_M52F` is itself a two-capture leg (its run 2 a harmless `missing_texture` capture)
   so the carried trail's close is observable after run 1; EXCL-B's FireOnce ticks come from `P_ORC_UV` (native order, the same
   schedule). If the trail closes within 24 frames of run 1's end, EXCL-A's run 2 takes pre = 0 (a DEFERred `IAI.Capture.Config`).
10. **G-REASON-DC's E6 cases** run in one capture refusing `bogus` plus DEFERred raw `IAI.Apply` for `drift` and the family case
    (the `ApplyAnomaly` path, ND-3).
11. **The doctored-label can-fail** runs at evaluation on each mode's AA-off fixture leg (onset ± 1, offset ± 1), not on all 16, to
    keep the evaluation inside the window.

    `texels_per_px ≤ 1.02`; negatives scored on the production mode's kept positions; a negative predicted to agree ≥ 50 % with

13. **The lock commit is made by the harness** (`lock --commit`, path-scoped, no push) so the premise → gates sequence fits one night;
