### Notes ruled "document" or "leave"
- **N3.** A `writer_timeout` frame can still land on disk after the summary is written. The summary marks the run
  stalled (`writer_stalled`); files that arrive later are not part of the run. In the readme.
- **N4.** On a lossy run the three target-mask counts can exceed `total_frames`; they add up to the frame count on a
  healthy run. In the readme.
- **N5.** After-offset settle entries take geometry frozen at `BeginRevert` (mid capture tick), not at the tick-end
  sample. Transition-only entries carry no label box, so nothing visible depends on it. Left as is.
- **S3 wording.** The ruling says "only the first onset and the final revert are flagged". In this code the held
  global is applied in `BeginActualRun` before the first captured frame and reverted in `FinishRun` after the last, so
  no captured frame follows either edge and **no frame is flagged**. The 095-02 plan already called it "a
  whole-session hold with no burst edge". If chat wants the first K frames of such a run flagged, that is a reader change too (session
  globals anchor nothing in the settle-placement check).
- **S5 limit.** Settle frames are recorded per transition track when the track is observed or at the start of each
  transition step; a render-truth snapshot processed out of order could miss a settle frame recorded later, which
  would make that window one frame shorter. Out-of-order snapshots are already counted (`label_out_of_order_frames`).
