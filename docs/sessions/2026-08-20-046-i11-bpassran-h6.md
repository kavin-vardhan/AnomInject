## 2. `H6`, and why the defect made its own test constructible

`bPassRan` (`AnomalyMaskMeasure.cpp:370`) tests `Mask.CustomStencilExtent` — **1×1 (the engine's
`StencilDummy`) or view-sized.** That answers *"was custom depth produced AT ALL for this view this
frame"*. It is used as *"did THIS TARGET write custom depth"*.

Tags accumulate: `AnomalyStencilTag.cpp` does not untag until `RestoreAll()` at `EndRun`. And the
extent goes view-sized if **any** primitive in the scene writes custom depth — it does not have to
be ours, and it does not have to carry a reserved tag.

⇒ **a target that contributed no evidence whatever can pass `bPassRan` and contribute a clean
`Count = 0`, which is `MEASURED_ZERO`, which is VETOED.**

### 2.1 🆕 THE IRONY, RECORDED BECAUSE IT READS AS LUCK OTHERWISE

The test was constructible because of **`H5`'s own defect**. Every gate on the arm path tests a
**FLAG**, never on-screen-ness:

| `AnomalyStencilTag.cpp:41` (`TagActor`) | `IsRenderableComponent` = `IsVisible()` ∧ type | a component visibility FLAG, plus a TYPE |
| `AnomalyMaskMeasure.cpp:454` (`SampleEndOfFrame`) | `AActor::IsHidden()` again | the same FLAG |

**None of them asks whether the target is on screen.** That is exactly `H5` — *renderable TYPE,
