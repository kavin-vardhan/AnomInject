## 5. The cause, with evidence

1. `ID_NN1`'s log refuses on every fire (six shown in `_leg\game.log`):
   `TEXCORRUPT-REFUSED family=normal mode=identity target='=StaticMeshActor_12' final=normal_unconnected step=V1 slots=1 qualified=0`
   The slot line reads `raw=M_TC_NN1 … bindings=1`, and the binding reads `param='Tex' … texture=T_TC_NN1 class=normal
   fmt=PF_BC5 srgb=0 normal_map=1`. It ends `Auto.FireSpecific: 'normal_corruption' on 'StaticMeshActor_12' -> not applied.`
   `annotation.json` has `anomalies: []`.
2. The feature (`TexCorruptTree.cpp`, V1): `if (Family == Normal && (!Root || !Root->IsPropertyConnected(MP_Normal)))` ⇒
   `FailSlot(RankA3, NormalUnconnected)`. In UE 5.1 this reads `FMaterialCachedExpressionData::PropertyConnectedBitmask`, a
   serialized `UPROPERTY` (`MaterialCachedData.h:249-256, 337`), so it holds in a cooked build.
3. The fixture (CaptureBench `tools/make_texcorrupt_fixture.py`, `readout(kind="normal")`) routes the sampler through a
   `NormalReadout` custom node into **`MP_EMISSIVE_COLOR` only**. The Normal pin is never connected. The same function builds
   `M_TC_UN1`, `M_TC_NN1`, `M_TC_ChainD` and `M_TC_NormalEmis`.
4. **The census showed this on the first leg of the window.** G0 F-SYN read `normal: normal_unconnected` on
   `StaticMeshActor_11`, `_12`, `_22`, `_32`, `_42`, `_52` and `_73`, i.e. every normal-fixture target. It raised **no
   finding**, because `ev_g0` compares only the `uv` family on F-SYN (`{'uv': exp.get(t[1:])}`), and G0 is D-class anyway.
5. The predictions file needed the normal id to apply on `TC_NN1` (row N-N1, every G4 normal exit, chain (d) through
   normal_corruption). It also lists `normal_unconnected` among the S2 producers that are "UNEXERCISED in S1". **Both cannot hold
   on this fixture:** every normal row in S1 is unreachable.

⇒ **Read:** the feature behaved as specified (§R6.4 V1), and the gate encoding (G3 needs ≥ 3 events) is correct. The defect is
the **fixture**: its normal readout materials cannot pass the feature's own admission rule. Neither the V1 predicate, the fixture
design nor the G3 rule is changed here.
