**M47 excusal** (`m47_assess`, `m47_closed_set`, `_m47_normalize_raw`, `legacy_view(…, m47=True)`):
- A leg is a candidate if it carries any row key or a non-zero summary value.
- **Signature:** exactly one PREWARM line, N ≥ 1.
- **Consistency:**
  - `shader_prewarm_incomplete` = N;
  - per row: exactly one SHADERS line; `anomaly_materials_incomplete` (0 when absent) = its `incomplete=`; `shader_jobs_pending` = its
    `pending=`; `render_state` = `shaders_pending`; the three keys all-or-none;
  - `frames_shaders_pending` = rows marked.
- **Healthy view:** the row keys removed and the two summary values set to 0, which is what the writer emits when nothing is incomplete.
  Every rule then runs unchanged on it: the pairs, key presence and the per-leg checks, with AMENDMENT 5's A views and B bijection intact.
- **Closed key set:** in that view, any path or stable field that differs from **every** other leg must be in the historical set, the
  timing-sampled set, or the diffs of the group's **other** control pairs. If not, the excusal is withdrawn and the pairs are rebuilt on
  the raw leg.
- **Cap and frequency** mirror A.4:
  - more than 1 excused leg in a group → NEEDS-DECISION;
  - `b3_all ≥ 2` with `pre_all == 0` → NEEDS-DECISION, over `legacy_prior_m47` (ledger group rows).
- **Reported:** `m47_excused`, `m47_assessment`, `m47_view_changes` (the paths the view moved, with an `only_frozen_m47_paths` flag),
  `m47_cap`, `amendment_6`. `run_legacy_group` writes `m47_excused` into the group row.
- A candidate that is **not** excused adds `<leg>: m47 keys present but not M47-EXCUSED (081-35 ruling 1): <why>` → FAIL.

**G297 reading and tripwire** (`g297_singletons`, `g297_tripwire`, `G297_BANK_BASELINE`, `legacy_prior_singletons`):
- The reading runs on the comparator's own pair diffs. Its fields and caught-by rules are in the predictions file. It is written as
  `self_excused_singletons`, `g297_caught_singletons` and `g297_field_singletons`, and into the group row.
- The tripwire covers the bank baseline (8 entries from §1: the 081-12 and 081-22 D groups plus c1 CB-N; c1 CB-S comes from its own row)
  plus every later group row.
- It adds a decision only when the current group contributes a build-3, non-historical self-excused singleton on the firing field.
- Field keys normalise the frame index and list positions (`labels/*/anomalies[]/bbox_px[]`). Binary classes are pre-m55 `0844220E`,
  build 3 `002805CF`, and "other" (the 081-12 stage builds count as neither).

**Readings unchanged.** `legacy_reading` / `_legacy_build` are untouched. The new lib's readings and flats are **fully identical** to

## Deviations
- **Closed key set is checked explicitly, against routes that exclude the leg's own control pair.** The ruling says "any key outside the
  frozen list → the ordinary rules, so FAIL". In synth order the ordinary rules self-excuse a value-only difference (G297), so "m47 keys
  plus one non-m47 difference → FAIL" could not come out as ruled through them. Proven both ways: the same `bbox_px` +1 on a leg without
  m47 PASSes and is listed as a self-excused singleton.
- **Consistency checks beyond the three ruled ones:**
  - exactly one PREWARM line;
  - exactly one SHADERS line per row;
  - `shader_jobs_pending` equals that line's `pending=`;
  - `render_state` equals `shaders_pending`;
  - the keys all-or-none;
  - a row without keys must read `incomplete=0`.

  All are writer-exact, and all are proven.
- **A candidate that is not excused adds its own FAIL line**, so a run_summary-only m47 value cannot slip through synth order.
- **Tripwire details:**
  - it adds a decision only when the current group contributes to the firing field (as A.4 does);
  - it counts path-level singletons only (field-level ones are reported);
  - it excludes historical fields exactly as ruled, and **does not** exclude timing-sampled fields. Today `coverage_pct` is suppressed
    by the pre-m55 D_N1/D_N4 singletons.
- **The bank baseline is a constant in the lib**, hash-pinned with it, not recomputed live. 081-22 C is left out of it (not a
  `legacy_compare` group; historical entries only).
- **Archive location:** `081-35-evidence/c1-invocation-4-081-34/`.
- **Order:** docs commit and push, then the boundary re-issue (081-33 precedent).
- **A pre-existing untracked `081-23-lib.py` sits at the plugin repo root in the main checkout.** It predates this session and was left
