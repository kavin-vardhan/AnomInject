## What changed

- R1: a target mask absent outside a run may use the nearest labelled boundary
  of that same run, at most `edge_window + BASELINE_MAX_FRAMES` frames away.
  N_BASE is the verifier's existing maximum of 24; the default distance is 28.
  Actual masks always take precedence. Every pair unions its two independently
  selected masks. Missing interior/boundary masks in a partly masked run and
  corrupt masks remain errors. Target selection requires the named target;
  a sole unrelated row entry cannot supply its ID or boundary template.
- Each affected observation prints its extrapolation source and maximum signed
  distance, including baseline use; structured detail retains every source/delta.
  Each run prints its maximum distance. NO-TRACE names extrapolated edge pairs.
  This is not 079-08 F2's boundary-mask reuse: there, real per-frame masks existed
  and were ignored; here, none exist.
- R2: zero-delta transitions coinciding with whole-region change remain CONSISTENT.
  The RUN line asks the reader to inspect frames k-1..k+1, and the event summary
  counts CONSISTENT events with a caveat. The old P1 prediction was wrong.
- R3: NO-TRACE means no change **above tau**, a fraction of target-region pixels.
  The one-pixel fixture has d=1/2500=0.0004, below tau=0.004, and stays NO-TRACE.
  P6 now asks whether an in-span/window pair exceeded tau.
- R4: event priority uses run outcomes only: NO-TRACE, OFFSET-NOTE, PARTIAL,
  CONSISTENT. Unassessable/reading runs remain visible in separate run coverage.
  `blank_missing_interior` is an UNASSESSABLE event. A consistent sibling can
  determine the event token without hiding an unread run's coverage.
- R5: producer-class contract, inclusive label bounds, duplicate-claim refusals,
  RGB-channel differences, endpoint extent and batch/exit contracts stay intact.

The old missing-end-mask `mixed_run` is now PARTIAL, with two scorer cells
(one recovered, one unassessable). A genuinely bbox-only run stays READING and
supplies zero scored cells. This interpretation was predeclared before results.
