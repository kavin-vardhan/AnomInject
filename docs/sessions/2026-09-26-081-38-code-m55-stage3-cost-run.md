## 4. The findings the run produced

1. **Pacing OFF collapses m55's required-pair yield on this recipe, at both resolutions.** Paced priors on the same recipe and binary read
   20/20 (`C2_SOLID_N_A1`, `C1_SOLID1080_S_A1`) with no `view_mismatch` and no `unsupported_delivery`. Pacing OFF, 720p: `view_mismatch`
   60–68, `unsupported_delivery` 22–28, `mask_payload_missing` 5–10 of 120 required windows per leg.
   - The `view_mismatch` rows have camera deltas of exactly 0. The mismatch is in the receipts: the mask payload is served from the view
     family **one earlier** than the colour frame (`S3_720_B1_T1` si 23: colour `view_family_id 24`/`family_frame 1779`, mask 23/1778).
   - `unsupported_delivery` rows carry `stage: mask` and `mask_receipt: null`.
   - This is G295's slipped/coalesced mask-serve shape (honest refusal, yield lost), far more frequent once pacing is off. **Mechanism beyond
     the receipts NOT established.**
2. **1080p pacing OFF drives m55 to its 256 MiB hard cap.** The writer is saturated (A1 32.83, B1 32.30 PNG/s against ~57–58 fps armed;
   backlog 141 frames; writer latency p50 ≈ 2.5 s). m55 holds colour/mask payloads until colour completion (p50 2.28 s, ~92 frames), so
   admitted bytes reached **267.64 MB (99.7 % of the cap)** at si 134 and **30 of 60 required windows were refused `budget_exceeded`**
   (134 rows). The cap and the refusal behaved as designed: rows dropped 0, late results 0, closure timeouts 0. The 256 MiB cap is not a
   memory problem; it is the reason the leg could not measure.
3. **1080p writer capacity on this box read 32.3–32.8 PNG/s**, below the declared 36–44 (bank). Both A and B, so not m55.
4. **Context:** pacing OFF saturates the CPU with the game itself (system busy ≈ 98–100 %; game ≈ 12.5–13.3 logical cores, ~10 of them
   background workers encoding PNGs). Foreign load was 0.69–1.00 cores mean, well inside the limits. The per-process GPU counter reads
   **0.0 % for the game** on every leg (foreign 0.01–0.14 %): the game's GPU load was not captured by the instrument; cause not established.
