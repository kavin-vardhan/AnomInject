## §3. The instrument

`python tools/verify_capture.py --label-pixel-gate --dir <session>` (m49 step 1, `b062832`), in gate
mode. Per event, per contiguous run of labelled frames, on the event's own region (the delivered mask
when present, else `bbox_px`):

- `d(k)` = fraction of region pixels differing by more than **8/255** from frame `k-1`.
- τ = `median + 6·MAD` of `d` over clean frames, floored at **0.0040**.
- **ONSET** aligned ⇔ `d(start) > τ` and `d(start-1) ≤ τ`.
- **END** aligned ⇔ `d(end+1) > τ` and `d(end) ≤ τ`.
- The reported edge is the **dominant** change in the bounded neighbourhood, never the first above τ
  (071-02 §11.3 defect 2), and the neighbourhood may not cross into another event's frames (defect 3).

⛔ **The instrument must re-prove it can FAIL before the first leg**, and its exit code is quoted in
the results: `python tools/verify_capture.py --label-pixel-gate --selftest` must print `SELFTEST: OK`
and exit **0** (seven cases, both edges, both directions — `G96`/`G142`).

## §4. THE PASS CONDITION, fixed now

**G-EDGE PASSES iff, on all EIGHT gate legs: `SHIFT == 0` and `NOT-VISIBLE == 0`, and at least one
event per leg is measurable.** Every leg's verifier exit code must be **0**.

**`NOT-MEASURABLE` is counted and reported, NEVER folded into PASS.** It is an unread surface. One
`NOT-MEASURABLE` per leg is EXPECTED BY CONSTRUCTION: the session's final event ends on or near the
last captured frame, so its end edge has no frame after it (`A50` TRUNCATED). Any OTHER
`NOT-MEASURABLE` reason is reported with the reason string and does not silently pass.

🚨 **A leg on which EVERY event is `NOT-MEASURABLE` is a FAILED GATE, not a pass** — that is the
vacuity shape `G146` exists for, and this clause is written before the legs so it cannot be argued
afterwards.

## §5. Refusal rules (a leg is discarded for HOW IT RAN, never for WHAT IT SHOWED — `A63`)

- The harness `run_leg.ps1` enforces `A63` itself: a leg that rode the 30 s focus-gate timeout is
  INVALID, discarded and re-run, up to 3 attempts; every attempt is banked including discarded ones.
  3 consecutive invalid attempts ⇒ HALT with **no verdict offered**.
- Pose gate `B1` + `A47` rotation gate ON. A pose failure is banked and re-run, labelled
  **"CAUSE NOT ESTABLISHED"** — never attributed.
- **A61-style refusal on the instrument:** the verifier exits **3** on a malformed/unreadable session.
  A 3 is a refusal, not a pass and not a failure; the leg is re-run.
- ⛔ **No leg is re-run because of the number it produced.** If a leg reads a SHIFT, the campaign
  STOPS and reports it verbatim. Re-running for green is `P30`'s laundering shape.

## §6. THE PREDICTION

**All eight gate legs read `SHIFT 0` / `NOT-VISIBLE 0`, exit 0, with exactly one `NOT-MEASURABLE`
per leg (the truncated final event).**

Grounds, stated so the prediction is falsifiable rather than decorative:

- Journal 071 §3.3 and §3.4 derive that for `missing_texture`/`corrupted_texture` (a `FireWindow` id)
  and `missing_object` (hide-in-`Apply`) the label edges are order-independent **by construction** on
  this code, in BOTH tick orders — the fire is created and the material swapped or the actor hidden in
  the SAME capture tick, and reverted likewise.
- For `blinking`, `m40` moved the active-state sample to `FWorldDelegates::OnWorldTickEnd`, which is
  after every tickable and before the draw, so the sampled bit is what the renderer will draw for that
  frame whatever order the subsystems ticked in. `P9` is closed on that basis.
- 071-02's known-answer runs already read `SHIFT 0` on five banked legs spanning both eras and both
  tick orders — but at the SHIPPED capture config and without an end-side assertion for
  `missing_object`, which is exactly what this gate adds.

**WHAT WOULD FALSIFY IT, and what each outcome would mean:**

| reading | meaning |
|---|---|
| any `ONSET-SHIFT(n)` on a `FireWindow` type | §3.3's derivation is WRONG — the label and the swap are not in the same tick. STOP. |
| any shift on `missing_object` only | the hide-in-`Apply` path differs from the derivation; the first end-side evidence for a hide type. STOP. |
| a shift present in SYNTH order and absent in NATIVE (or vice versa) | an order dependence survives `m40` for that type. STOP; this is the `P9` class re-opening. |
| `NOT-VISIBLE` on a `StaticMeshActor_49` leg | the target drew nothing on a leg where it demonstrably draws — suspect the INSTRUMENT first (071-02 §11.3 found three such), re-verify with `--selftest` before reporting a product finding. |

⛔ **No mechanism will be asserted from a G-EDGE reading** (`G120`). The gate reports alignment; it
does not explain it.
